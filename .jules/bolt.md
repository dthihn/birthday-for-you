## 2024-05-18 - Optimize Three.js Memory Allocations in Update Loops
**Learning:** Frequent instantiations of `THREE.Vector3` and `THREE.Matrix4` inside `update()` loops cause significant Garbage Collection (GC) pressure, leading to frame drops and jitter in Three.js animations. This codebase features a particle system where thousands of objects run their `update(dt)` function each frame.
**Action:** Prevent GC spikes by moving temporary math objects to the global module scope (e.g., `const _tempScale = new THREE.Vector3();`, `const _tempTarget = new THREE.Vector3();`, `const _invMatrix = new THREE.Matrix4();`). Reuse these objects via methods like `.set()`, `.copy()`, and `.applyMatrix4()` inside the high-frequency functions. Remember that some methods like `.applyMatrix4()` mutate the caller in place, so use a temporary vector to avoid unintended permanent mutations of the base position.
