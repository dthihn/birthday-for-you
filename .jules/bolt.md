## 2024-06-20 - Global THREE.js temp vectors must be declared after ES module imports
**Learning:** When trying to declare shared global temporary variables like `const _tempScale = new THREE.Vector3();` within a `<script type="module">` tag, JS module semantics dictate that they technically still work when placed before `import` statements (due to hoisting), but this violates universal style conventions and could trigger bundler/linter errors. Furthermore, the import statements can vary between similar HTML files in this project.
**Action:** Always inject dynamically declared script-level variables strictly *after* the final `import` statement. Using a regex search for `import\s+.*?;` and finding the last match is a safe way to identify the end of the import block across inconsistently structured files.
